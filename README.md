# Eleven Studio

Sito statico di Eleven Studio, importato dalla versione pubblica https://elevenstudiosite.netlify.app/.

## Pubblicazione
Collegare questo repository al progetto Netlify esistente, branch main. Nessun comando build; directory di pubblicazione: punto (.). Il file netlify.toml configura la directory.

Conservare googleb8c429dc50198be5.html per la verifica Search Console. Sitemap e canonical usano il dominio elevenstudiosite.netlify.app.

Il modulo contatti apre l’app email e non invia automaticamente i dati a un server.
